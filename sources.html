Field Guide / Sources

Go to the record

A source for the question you have.

Official documents, consumer resources and public collections. Each entry explains when it is useful.

A primary source helps establish what an institution published or announced. It can still contain disputed claims, limited data or a preliminary account. Read the original date and scope, then seek additional evidence when the conclusion is contested.

This directory is a starting point, not an exhaustive list or an endorsement of every statement on a linked site. For a named event, find the precise document or current local notice. For research, follow the collection's own guidance about access and rights.
