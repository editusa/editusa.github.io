About this project

A companion for curious readers.

The Edit USA Field Guide brings together original reference guides, public resources and a small practical tool.

Who publishes the Field Guide

This is an official Edit USA project. Edit USA is an independent digital news magazine based in Los Angeles, California, US. The Field Guide is a separate reference library hosted on GitHub Pages. Current news, features and recommendations are published at editusa.com.

The library covers questions that remain useful between news cycles: how to read a document's dates, compare recurring costs, plan a cultural outing or understand the limits of an intelligence record. The guides are original companion material, rather than copies of the magazine's articles.

Sources and illustrations

Guides link to official documents and resources where they support the subject. A primary source can describe an institution's own position without independently settling a disputed claim. The source directory explains what each resource can help you find.

The contextual illustrations were generated for Edit USA. They represent subjects such as reading, privacy and cultural visits; they do not depict actual events or reproduce official documents. Each displayed editorial illustration is credited to Edit USA.

Edit USA uses AI tools in research and writing and remains responsible for what it publishes. The magazine's editorial standards explain its broader approach. A source link or inclusion in this directory does not imply a partnership with the organization named.

Data on this companion site

This package contains no analytics tags, advertising trackers, sign-in, newsletter form or embedded third-party media. The cost comparison runs in the browser, and the directory search filters the resources already on the page. Neither tool sends entries to Edit USA or saves them in browser storage.

GitHub Pages provides the hosting and may process connection information under GitHub's privacy statement. Following an external link takes you to a site with its own practices. The main Edit USA website has separate features and privacy information.

Corrections and contact

If a guide contains an error or a resource has moved, contact Edit USA through the newsroom contact page. Include the Field Guide page address, the passage or link involved and the original record that supports the correction.
